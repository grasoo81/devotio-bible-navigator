# 성경 찾아가기 (devotio-bible-navigator)

Devotio Obsidian 볼트에 있는 **📖 성경 찾아가기.md** 노트를 위한 플러그인입니다.
성경 → 장(또는 편) → 절을 순서대로 고르면, 볼트 안의 장별 개역개정 노트를 열어
해당 절이 있는 줄을 찾아 선택해 줍니다. **본문 내용은 절대 바꾸지 않습니다.**

빌드 과정이 없는 순수 JavaScript 플러그인입니다 — `main.js`를 고치고
Obsidian에서 플러그인만 다시 불러오면(재시작 또는 끄고 켜기) 바로 반영됩니다.

## 지금 되는 것

- 왼쪽 리본에 📖 아이콘 → `📖 성경 찾아가기.md` 노트를 엽니다. (리본이 안 보이면
  명령 팔레트에서 "성경 찾아가기 열기" 명령으로도 열 수 있습니다.)
- 그 노트 안의 ` ```devotio-bible-navigator ` 코드블록 자리에 성경/장/절 선택 UI가 나타납니다.
- 절을 고르면 해당 장(편) 노트를 라이브 미리보기로 열고 그 줄을 선택합니다.
- **맥·PC**: 성경/장/절을 박스 3개로 나눠서 한 화면에 같이 보여줍니다. 장
  버튼을 처음 누르면 절 목록만 열리고, 같은 장을 다시 누르면 그 장 1절로
  이동합니다.
- **아이폰·아이패드**: 화면이 좁아서 박스를 쌓지 않고, 책 화면 → 장 화면 →
  절 화면으로 완전히 바뀌어 가며 고릅니다. 각 화면 위의 "‹ 뒤로" 버튼으로
  이전 화면으로 돌아갈 수 있습니다.

## 어떻게 작동하는가 (데이터 구조)

볼트의 `100. notes/170. 성경/구약|신약/<책 폴더>/` 안에 있는 노트들의
frontmatter를 그대로 읽어서 작동합니다. 책 목록·약어·장 개수를 코드에
하드코딩하지 않았으므로, 볼트 쪽 구조가 지금처럼 유지되는 한 책이나 장이
늘어나도 플러그인을 고칠 필요가 없습니다.

- 책 인덱스 노트 (예: `창세기.md`) — frontmatter: `type: bible-book`,
  `book`, `book_abbr`, `book_no`, `testament`
- 장/편 노트 (예: `창10장.md`, 시편은 `시100편.md`) — frontmatter:
  `type: bible-chapter`, `book_abbr`, `chapter`, `unit`(기본값 "장", 시편은 "편")
- 절 링크는 장 노트 본문 안에 `**[[창10_1|1]]**` 형태로 들어 있습니다.
  플러그인은 frontmatter의 절 개수를 믿지 않고, 이 본문을 직접 읽어
  실제로 존재하는 절 번호만 보여줍니다.

## 이 맥북에 설치하기 (개발용 — symlink)

```bash
bash scripts/install-mac.sh
```

볼트의 `.obsidian-apple/plugins/devotio-bible-navigator`를 이 폴더로 가리키는
심볼릭 링크로 만듭니다. 그래서 여기서 `main.js`를 고치면 볼트에도 바로
반영됩니다(복사가 아니라 링크라서 별도 설치 단계가 필요 없습니다).

설치 후 Obsidian에서: 설정 → 커뮤니티 플러그인 → "성경 찾아가기" 켜기.

## PC / 아이폰 / 아이패드에 설치하기 (BRAT)

이 볼트는 기기마다 설치된 플러그인을 따로 관리합니다(동기화 안 함). 그래서
각 기기에서 **BRAT**(Beta Reviewers Auto-update Tester) 플러그인으로 이
GitHub 저장소를 추가해야 합니다. (이미 설치돼 있는 `logos-ko` 플러그인도
같은 방식입니다.)

1. 그 기기에서 Obsidian 커뮤니티 플러그인 중 **BRAT**를 설치하고 켠다
   (아직 없다면).
2. 명령 팔레트(또는 BRAT 설정)에서 **"Add a beta plugin"** 선택.
3. 저장소 주소 입력: `grasoo81/devotio-bible-navigator`
4. 설치가 끝나면 설정 → 커뮤니티 플러그인에서 **"성경 찾아가기"**를 찾아 켠다
   (보안 때문에 기기마다 최초 1회 직접 켜야 합니다).
5. 왼쪽 리본에 📖 아이콘이 보이면 끝입니다.

저장소가 공개 저장소이므로 토큰 등록 같은 추가 단계는 필요 없습니다.
